# 领域专项：声音设计创意

> 📜 依据：[`../总纲.md`](../总纲.md) §2.0 主路由表
> 🎯 召唤条件：音乐制作 / Sound Design / 配乐 / 音效 / Foley / 混音 / 母带 / 样本筛选 / DAW 工程规划

## 1. 子类路由

| 子类 | 一审 | 二审 | 依据 |
|---|---|---|---|
| 含 YouTube 示范曲 / 教程 / Vlog 演示的议案 | **Gemini（强制）** | Claude（结构化评估） | 仅 Gemini 能"听/看"素材 |
| 纯参数规划（信号链 / 插件链 / 参数表 / DAW 工程结构） | **Claude** | Gemini | 结构化与一致性优先 |
| 风格参考与灵感发散 | **双轨并行** | 总统选择或综合 | 创意类不设默认权威 |
| 版权与样本合规审查 | **Claude** | Gemini | 法规核查侧 |
| 混音/母带的 A/B 听评 | **Gemini** | 总统（以耳决） | 素材听辨 |

## 2. 特别规则

### 2.1 Gemini 必读素材义务
议案附带的 YouTube 链接 / 音频文件 / 视频文件 / 图像频谱截图，Gemini 一审时**必须**逐一听或看，并在 `draft-01-gemini.md` 顶部列出：
- **素材清单**（名称 + 访问路径）
- **关键时间戳**（哪段几分几秒体现何种声学处理）
- **声学观察**（频段 / 动态 / 空间感 / 编排手法 / 情绪走向）

### 2.2 Claude 二审侧重
- DAW 工程可行性（CPU / RAM / 插件兼容性）
- 信号链是否存在冗余或相位问题的结构性风险
- 参数表是否自洽、可复现
- 版权合规（采样来源、Fair Use 边界）

### 2.3 迭代轮数豁免
声音设计类议案的收敛靠**主观听感**，不像代码有客观对错。**允许打破总纲 §2 Phase 3 的"1 轮反驳"上限**，改为"按总统主观听感决定是否继续迭代"。但每一轮必须：
- 产出可听的 A/B 样本放入 `artifacts/`
- 用 diff 清单标注本轮改了什么（哪个参数、哪段旋律）

## 3. 产出格式

| 产物 | 位置 | 内容 |
|---|---|---|
| 素材要点 | `artifacts/references.md` | Gemini 产出，时间戳 + 声学观察 |
| 信号链规划 | `artifacts/signal-chain.md` | Claude 产出，插件链 + 关键参数 |
| DAW 工程计划 | `artifacts/DAW-project-plan.md` | 轨道结构 + 总线路由 + 自动化点 |
| 最终工程文件 | `artifacts/` | `.als` / `.logicx` / `.flp` 等 |
| A/B 样本 | `artifacts/samples/` | `.wav` / `.mp3`，按轮次命名 |

## 4. 禁止事项

- ❌ Gemini 未听素材就出 draft（"凭文字描述猜"是严重违规）
- ❌ 使用未经核查版权的商业样本写入 `final.md` 而不提示
- ❌ Claude 以"非 Gemini 专业"为由规避二审（可读的参数表 / 工程结构仍属 Claude 领域）
