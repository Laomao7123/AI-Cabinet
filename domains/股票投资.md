# 领域专项：股票交易投资

> 📜 依据：[`../总纲.md`](../总纲.md) §2.0 主路由表 + **§2.5 高风险议题特别程序（最严格版）**
> 🎯 召唤条件：个股 / ETF / 期权 / 基金的买入卖出决策、仓位调整、止损止盈、组合再平衡、逆向交易触发
>
> ⚠️ **本域默认触发 §2.5 全部条款，且叠加以下加码条款。**

## 1. 路由：双轨独立分析（非接力）

议案到来后，**Gemini 与 Claude 同时、独立**开工，**互不阅读对方稿件**，直到总统收到两份稿件并决定是否合议。

## 2. Gemini 侧强制产出：`analysis-gemini.md`

| 段落 | 必含内容 |
|---|---|
| 2.1 信息面汇总 | 近期研报 / 新闻 / 管理层访谈 / 社媒热度（推特 / 雪球） |
| 2.2 **多模态素材摘录** | 若有管理层电话会议 / 路演 / YouTube 财经频道讨论，**直读**并摘关键发言时间戳 |
| 2.3 宏观与行业 | 相关板块 / 行业 / 政策背景 / 同业比较 |
| 2.4 风险点清单 | 明确列出已知风险，不得省略 |
| 2.5 结论（可为空） | Gemini 可选择"不给结论，只呈情报"——情报官本职 |

## 3. Claude 侧强制产出：`analysis-claude.md`

| 段落 | 必含内容 |
|---|---|
| 3.1 量化审视 | 估值指标（PE / PB / EV-EBITDA / 股息率 / 自由现金流），相对历史与同业分位 |
| 3.2 财报要点 | 营收/利润趋势 / 负债率 / 资本开支 / 回购分红 |
| 3.3 **逻辑严审** | 买入 / 卖出的**关键假设**与**被证伪条件**——若 X 发生则此逻辑破产 |
| 3.4 仓位建议 | 建议占组合 % / 止损位 / 止盈位 / 加减仓触发条件 |
| 3.5 **历史决策对照** | 读 `../archive/股票投资/` 历史档，指出与过去判断的一致或背离，识别重复错误 |

## 4. 禁止事项（加码条款）

- ❌ Gemini 与 Claude 在产出 `analysis-*.md` 前互相阅读对方稿件
- ❌ 适用"默认采信保守方"的 Phase 3 兜底法则（保守在投资域 = 机会成本损失，不是安全牌）
- ❌ 适用轻任务豁免
- ❌ **替代总统做出买卖动作**——两侧仅提供分析，**买卖按钮必须总统本人按下**
- ❌ 提供市场预测 / 点位预测 / "跑赢大盘"之类承诺性语言（两侧都不准）
- ❌ 在议案中包含他人（亲友 / 客户）的具体持仓信息——利益冲突防火墙

## 5. 强制归档结构

```text
archive/股票投资/{yyyymmdd}_{标的代码}_{动作}/
├── 00_议案.md
├── analysis-gemini.md
├── analysis-claude.md
├── decision.md              # 总统决定 + 当时逻辑 + 明确预期（价位/时间窗/止损位）
├── retrospective.md         # 事后复盘，按时间戳增量追加
│   ├── T+7:  ...
│   ├── T+30: ...
│   ├── T+90: ...
│   └── T+180:...
└── artifacts/               # 可选：图表截图 / 研报 PDF / 财报摘录
```

## 6. 复盘义务

- **T+30 复盘**：实际走势 vs. 预期，逻辑是否验证
- **T+90 复盘**：是否继续持有 / 加仓 / 清仓，理由
- **T+180 复盘**：总结方法论对错，提炼可迁移的经验或教训
- 复盘条目**允许诚实承认错误**——归档的目的是长期模式识别，不是自证正确

## 7. 免责声明（每份 `final.md` 末尾必含）

> 本议案内 Gemini 与 Claude 的分析仅为信息整理与逻辑推演，**不构成投资建议**。最终决策由总统 laomao 独立作出并自行承担全部结果。
