## 2. 特别规则

### 2.1 体验类议案的素材预处理
出游 / 探店类若附 Vlog / 短视频 / 图集，必走总纲 §2.6 素材预处理前置路由。Gemini 产出 `transcript-or-summary.md` 含：
- 地点实况（人流 / 装修 / 环境噪音）
- 菜品 / 体验亮点与槽点
- Vlog 博主的立场偏差提示（恰饭 / 自费）

### 2.2 健康 / 医疗议案的三条死线 🚨
1. **绝不替代医生**——任何 draft 末尾必含："本议案非医疗建议，所有用药 / 诊断 / 治疗决定请咨询持证医生。"
2. **禁止推荐具体处方药用量**——只可罗列就医准备事项、问诊问题清单、症状自我观察要点。
3. **触发 §2.5 高风险程序**——双轨独立分析，禁用轻任务豁免。

### 2.3 关系类议案的克制条款
- 不替总统写带情绪操纵性的文本（PUA / 冷暴力话术）
- 不代总统做关键关系决定（分手 / 绝交 / 离职）——只提供"若决定 X，如何表达"的执行级辅助
- 保留总统原始情绪表达的空间，不把所有沟通过度理性化

### 2.4 财务议案的边界
- 可做预算分配建议、消费复盘、订阅服务审计
- **不涉及具体投资决策**——那走 `domains/股票投资.md`
- **大额消费**（总统可自定阈值，默认 ¥5,000+）触发 §2.5

## 3. 产出格式建议

| 议案类型 | 主产物 |
|---|---|
| 行程 / 待办 | 时间线表 + `.ics` 日历文件（可选）+ Checklist |
| 财务预算 | 表格（分类 / 上限 / 已用 / 余额） |
| 出游规划 | Day-by-Day 行程 + POI 清单 + 预算表 |
| 探店 | POI 列表（名称 / 地址 / 特色 / 人均 / 推荐菜 / 避雷点） |
| 礼物 | 候选清单（选项 / 价位 / 匹配理由 / 采购渠道） |
| 就医准备 | 症状时间线 + 问诊问题清单 + 用药史 |
| 沟通脚本 | 原文 + 建议回复（可能多版本供总统选） |

## 4. 轻任务豁免适用性

- ✅ 可豁免：写一条回消息、列今日三件事、规划午饭吃什么
- ❌ 不可豁免：健康类、大额消费类、跨越一周以上的长期规划
