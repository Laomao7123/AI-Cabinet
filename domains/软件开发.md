# 领域专项：软件开发

> 📜 依据：[`../总纲.md`](../总纲.md) §2.0 主路由表
> 🎯 召唤条件：议案涉及代码编写 / 架构设计 / 脚本开发 / 运维部署 / 安全审计 / 技术文档

## 1. 子类路由

| 子类 | 一审 | 二审 | 依据 |
|---|---|---|---|
| 架构设计 / 前端 UI / 系统抽象 | **Gemini** | Claude | 全局视野 + 长链构思 |
| 本机脚本 / 文件系统 / Shell / 运维 | **Claude** | Gemini | Claude 直接持有 Bash 与文件工具 |
| 安全审计 / 漏洞修复 / 权限审查 | **Claude** | Gemini | 严谨与安全思维护城河 |
| 通用代码（算法 / 数据结构 / 库函数） | 谁先被叫到谁来 | 另一位 | 能力差不大，效率优先 |
| 纯文档 / 技术文案 | **Gemini** | Claude（仅事实核查） | 语言组织 |
| Debug（已知复现路径） | **Claude** | Gemini | 结构化排障 |
| Debug（跨越多系统 / 涉及视频录屏） | 按素材是否需要 Gemini 预处理决定 | 另一位 | 多模态素材需 §2.6 预处理 |

## 2. 产出格式要求

- **代码类产出**：实体文件必须写入 `artifacts/`；draft 中只放关键片段 + 注释。
- **架构类产出**：含 Mermaid 图 / 时序图 / 数据流图时，直接嵌入 markdown 渲染。
- **风险自述段**：起草人须在 draft 末尾列出"已知风险点 / 未覆盖边界 / 依赖假设"。
- **Claude 一审特权**：可就地把初版代码写入 `artifacts/`，让 Gemini 二审直接查阅真实文件，非纯文本纸上谈兵。

## 3. 执行前义务

严格适用总纲 §2 Phase 4 的**本机执行确认义务**：运行 `.py` / `.sh` / 数据库操作 / 文件批量重命名 / 网络请求等**前**，执行器须向总统复述命令 + 副作用（文件写入路径、是否覆盖、网络访问、是否启动常驻进程），得到确认后方可执行。

## 4. 特别条款

- **禁止破坏性操作无警告**：`rm -rf`、`git reset --hard`、`git push --force`、`DROP TABLE`、迁移脚本等**必须**在 `final.md` 顶部加 🚨 警示并获总统显式确认。
- **依赖新装义务**：`pip install` / `npm install` 非标准依赖前须列出依赖名 + 版本 + 来源。
- **Secret 处理**：涉及 `.env` / API key / Token 时，**绝不**将实际值写入议案或 draft，用占位符（如 `<API_KEY>`）。
